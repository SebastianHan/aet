description: AET entry point - routes to appropriate workflow based on intent (feature development, bug fix, project analysis, configuration, etc.)
agent: aet-router
---

Start an AET workflow by invoking the aet-router agent.

The router will analyze your intent and route you to the appropriate workflow:
- **Feature Development**: Provide an issue URL or describe the feature to develop
- **Bug Fix**: Describe the bug or issue you want to fix
- **Project Analysis**: Request to analyze the project architecture and structure
- **Configuration Setup**: Request to initialize or configure project settings
- **Agent/Skill Development**: Request to develop new agents, skills, or commands

Simply describe what you want to accomplish, and the router will guide you to the right workflow.
