# 创新评估标准矩阵

## 定位

在创新发现过程中，用于创意筛选、优先级排序和决策辅助。

---

## 1. 三维评估模型

对每个创新机会/创意，从三个维度进行独立评估。

### 评估维度

| 维度 | 含义 | 评估问题 |
|------|------|---------|
| 价值潜力 | 成功后能带来的价值大小 | 解决的是真问题吗？市场规模多大？ |
| 可行性 | 当前条件下的实现难度 | 技术可行吗？资源够吗？能按时完成吗？ |
| 差异化 | 与现有方案的独特程度 | 为什么别人做不了？我们有什么优势？ |

### 评分标准

每个维度1-5分：

| 分数 | 价值潜力 | 可行性 | 差异化 |
|------|---------|--------|--------|
| 5 | 改变行业/影响巨大 | 无障碍，当前可做 | 开创性，无直接竞争 |
| 4 | 显著价值提升 | minor障碍 | 明显差异 |
| 3 | 中等价值 | 需要努力但可实现 | 有一定差异 |
| 2 | 有限价值 | 较大障碍 | 差异较小 |
| 1 | 几乎无价值 | 几乎不可能 | 无差异 |

### 综合评分

```
综合分数 = 价值 × 0.5 + 可行性 × 0.3 + 差异化 × 0.2
```

### 决策参考

| 组合 | 类型 | 决策 |
|------|------|------|
| 价值≥4, 可行≥4 | 明星机会 | 立即执行 |
| 价值≥4, 可行≤2 | 赌注机会 | 评估是否值得赌 |
| 价值≤2 | 瘦狗机会 | 放弃或暂缓 |
| 可行≤2 | 高风险 | 需要先验证可行性 |

## 2. 创新类型分类

### 分类标准

| 类型 | 定义 | 特征 | 风险 |
|------|------|------|------|
| 维持性创新 | 现有产品/服务的增量改进 | 已有用户群、可预测 | 较低 |
| 突破性创新 | 改变现有市场规则 | 新市场、新用户 | 中等 |
| 颠覆性创新 | 从边缘切入，逐步取代主流 | 非主流用户开始 | 较高 |

### 评估要点

**维持性创新**：
- 我们比竞争对手做得更好吗？
- 用户愿意为改进付钱吗？
- 能在多长时间内推出？

**突破性创新**：
- 新市场是否真实存在？
- 能否建立早期领先地位？
- 规模化的路径清晰吗？

**颠覆性创新**：
- 为什么不从边缘开始？
- 主流通用会如何回应？
- 我们能承受多久的亏损？

## 3. 风险评估矩阵

### 风险类型

| 类型 | 描述 | 评估问题 |
|------|------|---------|
| 市场风险 | 用户不接受的概率 | 用户真的需要吗？愿意付钱吗？ |
| 技术风险 | 技术不可行的概率 | 技术成熟吗？有什么障碍？ |
| 执行风险 | 团队无法交付的概率 | 团队有能力吗？资源够吗？ |
| 竞争风险 | 被竞争对手超越的概率 | 壁垒在哪？竞争对手会如何反应？ |
| 资金风险 | 资金耗尽的可能性 | 需要多少钱？能支撑多久？ |

### 风险评分

每个风险按"概率 × 影响"评分：

| 分数 | 概率 | 影响 |
|------|------|------|
| 5 | >80% | 灾难性 |
| 4 | 60-80% | 严重影响 |
| 3 | 40-60% | 中等影响 |
| 2 | 20-40% | 轻微影响 |
| 1 | <20% | 可忽略 |

### 风险应对策略

| 风险等级 | 综合风险分 | 策略 |
|---------|-----------|------|
| 高风险 | >15 | 必须缓解才能推进 |
| 中风险 | 8-15 | 制定缓解计划 |
| 低风险 | <8 | 接受，持续监控 |

## 4. 优先级排序规则

### 象限图

```
                    价值
                      ↑
                      │
         ⭐ 明星      │     🎯 核心
         (高价值      │     (高价值
          低可行性)    │      高可行性)
                      │
    ──────────────────┼──────────────────→ 差异化
                      │
         💀 瘦狗      │     🔮 投机
         (低价值      │     (低价值
          低可行性)    │      高可行性)
                      │
                      │
                      │
                   可行性
```

### 决策规则

1. **明星机会**：优先投入资源，快速验证
2. **核心机会**：立即执行
3. **投机机会**：评估后决定是否探索
4. **瘦狗机会**：暂缓或放弃

## 5. 阶段gate决策

### Gate 1: 问题发掘结束

| 条件 | 决策 |
|------|------|
| 问题清晰、可验证 | 通过，进入机会验证 |
| 问题模糊 | 返回重新定义 |
| 问题无价值 | 终止 |

### Gate 2: 机会验证结束

| 条件 | 决策 |
|------|------|
| 至少1个假设验证通过 | 通过，进入创意生成 |
| 核心假设失败 | 返回或终止 |
| 不确定 | 继续验证或Pivot |

### Gate 3: 创意生成结束

| 条件 | 决策 |
|------|------|
| 有2+个创意通过初筛 | 通过，进入原型验证 |
| 无创意通过 | 返回重新生成 |
| 只有一个 | 扩大探索范围 |

### Gate 4: 原型验证结束

| 条件 | 决策 |
|------|------|
| 达到预设成功标准 | 通过，进入商业建模 |
| 未达到 | 返回或Pivot或终止 |
| 部分达到 | 评估后决定 |

### Gate 5: 商业建模结束

| 条件 | 决策 |
|------|------|
| 商业模式可行 | 通过，进入规模化 |
| 商业模式不可行 | 返回或终止 |

## 7. 使用建议

1. **评估时机**：每个阶段结束、Gate决策时
2. **评分依据**：基于证据而非直觉
3. **多人评估**：建议2-3人独立评估后讨论
4. **动态更新**：获得新信息后重新评估
5. **文档记录**：保留每次评估的理由和证据
