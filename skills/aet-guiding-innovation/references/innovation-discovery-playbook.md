# 创新发现完整工作流程

## 定位

本文件提供端到端的创新发现系统化流程，适用于复杂创新项目。

## 流程概览

```
阶段1: 问题发掘 → 阶段2: 机会验证 → 阶段3: 创意生成 → 阶段4: 原型验证 → 阶段5: 商业建模
```

---

## 阶段1: 问题发掘

### 输入
- 初步业务挑战或用户反馈
- 可选：市场调研报告、竞品分析

### 核心步骤

1. **用户与场景洞察**
   - 明确"谁在什么情境下遇到什么阻碍"
   - 区分表面诉求与真实动机
   - 识别任务链条中的高摩擦节点

2. **问题定义**
   - 使用单句问题陈述模板：`某类用户在某情境下，因某原因无法达成某目标`
   - 避免预设解法的问题表述

3. **问题重构**
   - 用不同视角重述问题，扩展机会空间
   - 常用模板：How Might We（我们可以如何…）

4. **机会筛选**
   - 以"价值潜力 × 可行性 × 差异化"进行初筛
   - 高价值高确定性：立即进入下一阶段
   - 高价值高不确定性：标记待验证假设

### 输出
- 问题陈述（不含解法）
- 初步用户画像
- 关键不确定性清单

### Agent执行要点
- 使用question-templates.md中的痛点挖掘问题集进行访谈引导
- 记录用户原话中的情绪词汇和高频痛点

---

## 阶段2: 机会验证

### 输入
- 阶段1输出的问题陈述
- 待验证假设清单

### 核心步骤

1. **假设验证设计**
   - 将每个问题转化为可验证假设
   - 设计最小验证实验（访谈、调研、A/B测试）

2. **验证执行**
   - 按优先级执行验证实验
   - 记录正/负证据

3. **机会评估**
   - 使用evaluation-matrix.md三维评估
   - 决定：深入/调整/放弃

### 输出
- 经过验证的问题陈述
- 假设验证结果
- 优先级排序

### Agent执行要点
- 优先验证高风险假设
- 用数据支持决策，避免直觉

---

## 阶段3: 创意生成

### 输入
- 经过验证的问题陈述
- 约束条件清单

### 核心步骤

1. **发散思维**
   - 使用SCAMPER、奥斯本检查表等工具
   - 追求数量，暂不评价

2. **跨领域启发**
   - 借鉴其他行业解决方案
   - 应用类比推理

3. **收敛评估**
   - 使用价值/可行性/差异化筛选
   - 选择Top 3-5创意进入下一阶段

### 输出
- 创意候选清单
- 每个创意的初步评估
- 推荐优先级

### Agent执行要点
- 结合triz-guide.md中的矛盾分析方法
- 记录创意的创新点和潜在风险

---

## 阶段4: 原型验证

### 输入
- 精选创意方案
- 可用资源与时间约束

### 核心步骤

1. **原型设计**
   - 确定原型类型（概念原型/功能原型/体验原型）
   - 设计验证目标

2. **快速构建**
   - 用最小成本制作原型
   - 保持原型可抛弃性

3. **用户测试**
   - 选择目标用户进行测试
   - 收集反馈并迭代

4. **验证决策**
   - 通过：进入商业建模
   - 失败：返回创意生成或终止

### 输出
- 原型测试报告
- 用户反馈摘要
- 迭代决策

### Agent执行要点
- 参考lean-startup-guide.md中的MVP方法
- 设定明确的成功/失败标准

---

## 阶段5: 商业建模

### 输入
- 通过验证的原型
- 用户测试数据

### 核心步骤

1. **商业模式设计**
   - 使用商业画布九宫格
   - 明确收入来源和成本结构

2. **财务预测**
   - 初步收入模型
   - 盈亏平衡分析

3. **风险评估**
   - 识别关键风险
   - 制定应对策略

4. **决策**
   - 可行：进入规模化实施
   - 不可行：返回适当阶段或终止

### 输出
- 商业模式画布
- 财务预测摘要
- 风险缓解计划

---

## 阶段间过渡判断标准

| 从 → 到 | 过渡条件 |
|---------|---------|
| 问题发掘 → 机会验证 | 问题陈述清晰、有2+个可验证假设 |
| 机会验证 → 创意生成 | 至少1个假设被验证为正、问题具有足够价值 |
| 创意生成 → 原型验证 | 有2+个创意候选、通过初筛评估 |
| 原型验证 → 商业建模 | 原型测试达到预设成功标准 |
| 商业建模 → 规模化实施 | 商业模式可行、风险可控 |
